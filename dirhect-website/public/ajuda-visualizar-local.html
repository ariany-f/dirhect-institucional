Como visualizar o site (desenvolvimento local)

  1. Abre o terminal na pasta do projeto: dirhect-website (não na raiz ProjetoDirhect só, a menos que o package.json esteja lá).
  2. Instala dependências uma vez: npm install
  3. Inicia o servidor: npm run dev — ou já abre no programa de parceiros: npm run dev:parceiro
  4. No terminal, o Vite mostra o endereço (porta 5191 se estiver livre; se aparecer 5192, 5193, etc., usa esse URL). Abre no browser:
    • http://127.0.0.1:5191/parceiro (página do parceiro)
    • http://127.0.0.1:5191/ (home)
  5. Se a porta 5191 estiver ocupada, o Vite escolhe outra (ex. 5192) — usa exatamente o URL que aparecer no terminal.
  6. Para abrir o browser automaticamente: npm run dev:open (home) ou npm run dev:parceiro (abre /parceiro).

Página em branco em /parceiro? A app carrega o ficheiro estático /parceiro-template.html. Abre /parceiro-template.html — se der 404, o ficheiro não está em public/parceiro-template.html ou o servidor não é o deste projeto.
